## 📁 Project Files

- `style.css`
- `script.js`
- `README.md`
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`

## 🚀 GitHub Pages Setup

1. Upload all files to the repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/(root)`.
5. Click **Save**.
6. Wait for GitHub Pages to publish the website.
